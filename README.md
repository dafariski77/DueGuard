# DueGuard (v1.0 MVP)

Personal & Household Renewal Guardian — Never get caught by surprise renewals again.

## Tech Stack
- **Backend:** NestJS, Prisma ORM, PostgreSQL, Redis, BullMQ
- **Mobile:** React Native (Expo SDK 52+), TypeScript, Expo Router
- **Shared:** TypeScript DTOs, Zod schemas, Shared Enums
- **Infrastructure:** Docker Compose, Isolated Internal Network
